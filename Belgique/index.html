Ouvrir la requête

Une ligne par point : « latitude, longitude » (séparés par une virgule, un point-virgule ou une tabulation). Un fichier CSV avec les en-têtes latitude / longitude est aussi accepté, par exemple celui exporté par cette page. Un fichier GPX (trace, itinéraire ou points de passage) est aussi accepté. Un fichier KML contenant une polyligne est lu sommet par sommet. Une troisième valeur facultative sur une ligne (l’altitude du fichier GPX) est comparée à l’altitude calculée.
